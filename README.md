# Mandarin audio stimuli

This repository contains the Mandarin audio stimuli and the corresponding experimental materials used in the forced-choice experiment reported in the thesis *Questions in Yuancheng-Zhongxin Hakka*.

Although the repository is named `mandarin_audio`, it also includes the spreadsheet and CSV files used for the Mandarin experiment.

## Contents

This repository includes:

- `Mandarin_materials.xlsx`: spreadsheet containing the Mandarin target items, filler items, and practice items.
- `itemscibles.csv`: CSV file containing the Mandarin target items.
- `fillers.csv`: CSV file containing the Mandarin filler items.
- `practice.csv`: CSV file containing the Mandarin practice items.
- `.wav` files: audio stimuli used in the Mandarin experiment.

## File naming convention

The audio files are named according to the following system:

- `MAN` = Mandarin Chinese
- item number = experimental item number
- `P` = practice item
- `F` = filler item
- `Q` = question stimulus
- `A` = answer stimulus
- `Focus` = focus condition
- `Topic` = topic condition
- `TopicM` = marked topic condition
- `Preference` = preference question in filler items
- `CommonKnowledge` = Common Knowledge question in filler items
- `Left` / `Right` = answer position in filler items 

For example:

- `MAN-1-Q-Focus.wav` refers to Mandarin item 1, question stimulus, focus condition.
- `MAN-1-Q-Topic.wav` refers to Mandarin item 1, question stimulus, topic condition.
- `MAN-1-Q-TopicM.wav` refers to Mandarin item 1, question stimulus, marked topic condition.
- `MAN-1-A-Focus.wav` refers to Mandarin item 1, answer stimulus, focus condition.
- `MAN-1-A-Topic.wav` refers to Mandarin item 1, answer stimulus, topic condition.
- `MAN-F8-Q-Preference.wav` refers to Mandarin filler item 8, preference question.
- `MAN-F8-Q-Preference.wav` refers to Mandarin filler item 8, preference question.
- `MAN-F15-Q-CommonKnowledge.wav` refers to Mandarin filler item 15, Common Knowledge question.
- `MAN-F8-A-Right.wav` refer to the left answer option for filler item 8.
- `MAN-P1-Q-Focus.wav` refers to Mandarin practice item 1, question stimulus, focus condition.

## Audio format

All audio stimuli are provided in `.wav` format.

## Experimental materials

The file `Mandarin_materials.xlsx` provides an overview of the Mandarin experimental materials. The CSV files are provided for accessibility and can be used directly with the PCIbex experimental scripts.

The materials include:

- target items;
- filler items;
- practice items;
- corresponding question and answer stimuli;
- condition labels used in the experiment.

## Related thesis

These materials were prepared for the Mandarin forced-choice experiment in the study:

*Questions in Yuancheng-Zhongxin Hakka*

## Notes

The repository is intended to make the experimental materials and audio stimuli accessible for verification and reference. No participant data are included in this repository.
